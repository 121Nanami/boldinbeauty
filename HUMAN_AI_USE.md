## Working rules

- These are project recommendations, not measured rankings. Pick the best fit for the task and tools actually available; begin at the listed strength and raise it only when the work needs it.
- Use [OpenAI model guidance](https://learn.chatgpt.com/docs/models) and the actual selector. GPT-6.1 Sol is a current project option; larger or faster modes remain conditional on task need and included entitlement.
- Model names, plan access and effort controls can change. Check the current interface and the detailed notes in `BoldInBeauty_MAIN` if a model is missing or the task needs an unlisted capability.
- The owner uses Claude Pro and confirms Opus 5.5 is usable. Choose its actual available model and entitlement; do not retain the older no-Claude-allowance assumption.
- Use ChatGPT Images 2.5 for prototype visuals only: mood boards, silhouette/style exploration, rough composition and material/color studies. Treat outputs as references for discussion, not production-ready game assets or approved canon. The owner has ChatGPT Plus; the image feature is included in ChatGPT plans, while API use is separate. Check current plan limits and feature availability in the app. [Images in ChatGPT](https://help.openai.com/en/articles/11084440)
- Do not buy credits, API access, top-ups or overages without approval. API model listings do not grant API usage.
- Check facts, code, calculations and finished artifacts. Recommendations do not change project canon or replace the owner's decisions.
- When collaborating under the owner's standing authorization, keep assignments bounded, record actual models, protect others' work, coordinate one MAIN writer and check results against evidence.
