# Supporting project files

SHARED placement convention · 2026-09-30 · Newly assigned for this filing task.

Use this existing folder for explicitly obtained or generated supporting attachments and exports that are neither research text, technical reports nor Unreal source/assets. Keep source provenance, date and status alongside each real attachment. Use topic subfolders only when there is an actual file to store. Do not copy credentials, host connection settings, engine/vendor trees, caches or entire repositories here.

Existing root character workshop files retain their locations. Native Unreal assets stay in the selected Unreal project and use editor-supported filing. Research belongs in `Research/` or established `research_notes/`; verified task evidence belongs in `reports/`. See [the folder map](../reports/filing/README.md).

No attachment/export files have been added by this setup; only this placement guide was created. Windows placement and cross-device equality remain OPEN.
