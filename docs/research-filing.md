# Research placement

SHARED procedure · 2026-09-30.

`Research/` is the existing research and synthesis input/output area. Research-agent outputs follow `Research/<Domain>/<Topic>/<descriptive-name>.md`; reuse an existing relevant topic before creating a folder. `research_notes/` holds existing source notes, including `Boldinbeauty marketing plan/`; preserve originals and keep it distinct from `Research/`. Research needs dated sources, evidence status and traceable citations.

Operational guides and templates live outside `Research/`. The drafting procedure now accepts explicit research Markdown paths assigned by the lead, including nested `Research/<Domain>/<Topic>/` files. Recursive discovery locates the selected inputs; it does not draft all Markdown automatically. Skip indexes, templates, handoffs, administrative README files and unselected notes. If the caller supplies a goal rather than paths, consult the lead with relevant candidate paths and continue independent preparation; do not process the entire tree automatically. Preserve each source path in document provenance. This procedure resolves the documented folder mismatch; an actual drafting run and cloud filing remain OPEN until performed and checked.

Use [the report template](../reports/templates/agent-report.md) for research findings that need MAIN integration. New research topics require an actual assigned research artifact; do not create speculative categories. No research or creative content was moved or rewritten by this filing task.
