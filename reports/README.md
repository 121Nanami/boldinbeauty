# Reports

Task evidence belongs here. Keep existing report paths stable. Create a named topic folder only when filing a real new report; include date, agent and task in its filename. Each report distinguishes verified results from WORKING proposals, OPEN issues, DEFERRED work and historical SNAPSHOTs.

| [Integration setup](integration-setup.md) | Existing dated integration findings; recheck before relying on current health |
| [Marketing plan](<Boldinbeauty marketing plan.md>) | Existing marketing report |

Return reports to the accountable lead; the lead integrates durable knowledge into MAIN under the coordinated writer protocol. A report file does not prove delivery, external publication or counterpart verification.
